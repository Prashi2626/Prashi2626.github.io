# My Personal Finance Tracker V15 — Dashboard update

## Dashboard changes
- Income received this month through today.
- Bill payments recorded this month and unpaid bills due this month.
- Daily expenses total for the current month through today.
- EMI installments marked paid this month and upcoming EMIs due this month.
- Room rent paid/due summary.
- Due bills and upcoming EMI lists with links to Bills, Payments and EMIs.
- Quick Room Rent bill creation.

## EMI payment behavior
Using **Mark EMI Paid** now records an entry in Payments (with an EMI installment note), increments the paid-installment count, and moves the next due date forward by one month. Please use this action once per installment; don't also add a duplicate payment manually.

## Room rent and payments
- Go to Dashboard → **+ Add Room Rent Bill**, or Bills → Add Bill.
- Add the monthly amount and due date; the quick action pre-fills Room Rent, Rent, Monthly, and Pending.
- To record payment, use Dashboard → **+ Record Bill Payment** or Payments → Record Payment, then select the Room Rent bill.
- For daily purchases and other non-bill spending, use Daily Expenses.

## Deploy
Upload/replace `index.html`, `sw.js`, and this README in the GitHub repository. Keep the existing `config.js` unchanged. No SQL migration is required. The current Supabase tables are reused.

## Counting rules
Dashboard totals are calculated from records dated in the current month and not later than today's date. EMI paid-this-month totals are tracked from payment rows generated by the **Mark EMI Paid** action; older EMI payments without such history cannot be reconstructed automatically.
